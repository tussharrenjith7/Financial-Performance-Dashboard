# 📊 Financial Performance Dashboard

## Overview
An interactive Tableau dashboard created to analyze financial performance across products, customer segments, countries, and time periods.

## Objective
The objective of this project is to provide business insights through interactive visualizations that help stakeholders monitor revenue, profit, and overall financial performance.

## Tools Used
- Tableau
- Microsoft Excel
- Data Visualization

## Dashboard Features
- Revenue by Month
- Revenue by Country
- Revenue by Product
- Revenue by Customer Segment
- Profit by Month
- Profit by Country
- Profit by Product
- Interactive Filters

## Key Insights
- Compared revenue trends across different months.
- Identified the most profitable products.
- Evaluated performance across countries.
- Analyzed customer segments contributing to revenue.
- Built an interactive dashboard for business reporting.
